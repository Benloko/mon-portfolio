## 🌐 Déploiement sur Vercel (En 2 Minutes)

### Option 1 : Déploiement direct via le terminal (Ultra rapide)
Dans le terminal du projet, lancez simplement :
```bash
npx vercel
```
- Répondez **Y** pour configurer le projet.
- Conservez les valeurs par défaut (appuyez sur Entrée).
- En quelques secondes, Vercel vous donne votre lien public direct (ex. `https://portfolio-benloko.vercel.app`) !

### Option 2 : Déploiement via GitHub
1. Créez un nouveau dépôt sur votre compte GitHub [github.com/Benloko](https://github.com/Benloko) (ex. `mon-portfolio`).
2. Poussez votre code :
   ```bash
   git init
   git add .
   git commit -m "Mon portfolio professionnel React"
   git branch -M main
   git remote add origin https://github.com/Benloko/mon-portfolio.git
   git push -u origin main
   ```
3. Rendez-vous sur [vercel.com](https://vercel.com), connectez votre compte GitHub et cliquez sur **« Add New Project »** en sélectionnant `mon-portfolio`.
4. Cliquez sur **Deploy** : le site est en ligne instantanément !
